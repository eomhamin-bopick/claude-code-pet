# 사용량 표시

머리 위 알약(`5h 19% · 7d 21%`)은 `~/.claude-pet/state/.usage` 파일 한 줄을 읽어서 그립니다.

```
<5시간 %>|<7일 %>|<기록 시각(epoch 초)>
19|21|1792719174
```

- 없는 창은 `-1`로 씁니다. 둘 다 없거나 파일이 없으면 알약은 숨겨집니다.
- 기록한 지 6시간이 지난 값은 쓰지 않습니다 (오래된 숫자가 계속 떠 있지 않게).
- 70% 이상이면 알약이 연한 분홍, 90% 이상이면 진한 분홍으로 바뀝니다.
- 이 파일을 **누가 채우느냐**만 정하면 됩니다. 아래 세 가지 방법이 있습니다.

값을 쓰는 스크립트는 이미 들어 있습니다.

```bash
~/.claude-pet/hooks/pet-usage-set.sh 19 21     # 5시간 19%, 7일 21%
```

## A. 상태줄로 자동 (Pro/Max 구독)

Claude Code는 Pro/Max 구독 계정에서 상태줄 입력에 `rate_limits`(5시간, 7일 사용 %)를 넣어 줍니다. 설치할 때 옵션을 주면 기존 상태줄을 그대로 두고, 그 앞에 값을 기록하는 래퍼를 끼웁니다.

```bash
./install.sh --statusline
```

- 원래 상태줄 설정은 `~/.claude-pet/statusline.orig.json`에 보관하고, `~/.claude-pet/app/uninstall.sh`가 원래대로 돌려 놓습니다.
- 쓰던 명령은 `sh -c '<원래 명령>'`으로 감싸서 실행하므로 `FOO=1 cmd`나 `a && b` 같은 셸 문법도 그대로 동작합니다.
- `rate_limits`가 오지 않는 계정(예: Team 플랜)에서는 값이 안 들어오고 알약은 숨겨진 채로 있습니다. 그 경우 B나 C를 쓰세요.
- 상태줄은 터미널의 `claude` 화면용 기능입니다. 데스크톱 앱 안에서만 쓰면 실행되지 않을 수 있습니다.

## B. 직접 채우기

어떤 방법으로든 숫자를 알 수 있다면 `pet-usage-set.sh`를 부르면 됩니다. 예를 들어 `launchd`나 `cron`으로 주기적으로 실행하는 스크립트에서 쓸 수 있습니다.

## C. Claude 데스크톱 앱의 예약 작업 (앱이 사용량 카드를 보여 주는 계정)

앱의 사용량 카드를 읽을 수 있는 도구가 있는 환경에서는, 예약 작업이 값을 읽어 `pet-usage-set.sh`에 넘기게 할 수 있습니다. 작업 프롬프트 예시입니다 (도구 이름은 앱 버전에 따라 다를 수 있으니 환경에서 확인하세요).

```
[pet-quiet] 이 작업은 사람이 보지 않는 유지보수 작업입니다. 아래만 하고 끝내세요.

1. 사용량을 읽는 도구(예: get_usage)를 인자 없이 호출합니다.
2. plan.status 가 "ok"가 아니면 "usage unavailable"이라고만 답하고 아무것도 쓰지 않습니다.
3. plan.windows 에서 "5-hour limit"의 percentUsed(five)와, "Weekly"로 시작하고 all models 가 들어간 창의 percentUsed(week)를 꺼냅니다. 없으면 -1.
4. Bash 로 정확히 한 번만 실행합니다: bash ~/.claude-pet/hooks/pet-usage-set.sh <five> <week>
5. 그 출력 한 줄만 답하고 멈춥니다. 다른 파일을 읽거나 쓰지 마세요.
```

주의할 점:

- **실행할 때마다 새 세션이 하나씩 만들어집니다.** 세션 목록에 쌓이고, 사용량도 조금씩 씁니다. 간격은 **1시간 이상**을 권합니다 (30분마다 돌리면 하루에 30개 넘게 쌓입니다).
- 앱이 켜져 있어야 돌아갑니다.
- 사람이 보지 않는 무인 작업이 Bash를 쓰게 되므로 **허용 범위를 좁히세요.** 이 작업에는 `bash ~/.claude-pet/hooks/pet-usage-set.sh` 한 가지 명령만 허용하면 충분합니다. 다른 명령이나 파일 쓰기 권한은 주지 마세요. 숫자는 `pet-usage-set.sh`가 정규식으로 검증해서 그 밖의 값은 받지 않습니다.
- 프롬프트 앞의 `[pet-quiet]`는 이 작업 세션이 펫을 움직이거나 알림음을 내지 않게 하는 표시입니다. 빼면 작업이 돌 때마다 펫이 반응합니다.
- 값이 한 번 기록되면 6시간 동안 보입니다. 이 작업의 간격이 길면 숫자가 실제보다 오래된 값일 수 있습니다.
